# 医疗专家系统（规则推理引擎）

离散数学课程项目：用 Python 实现一个**基于规则的医疗专家系统**，包含推理引擎、知识库与改进版实现，重点在于规则的组织方式与推理过程的可解释性。

## 项目结构

```
├── inference_engine.py                 # 推理引擎（规则匹配 / 冲突处理 / 推导链）
├── knowledge_base.py                   # 知识库（症状 → 规则的映射）
├── improved_medical_expert_system.py   # 改进版主程序（交互入口）
└── discrete_math.py                    # 离散数学工具（关系 / 集合运算等）
```

## 运行

```bash
python improved_medical_expert_system.py
```

按提示输入症状，程序输出推断结论与**推导链**（命中了哪些规则、依据是什么）。

## 这个项目里值得看的：规则类系统的验证

规则推理引擎属于「输入确定、输出确定、但组合爆炸」的系统，测试的难点不在主流程，而在：

1. **规则冲突**：多条规则同时命中、结论互相矛盾时，引擎的选择是否符合优先级定义；
2. **边界输入**：空输入、单症状、全症状、知识库中不存在的症状；
3. **可解释性**：同样的输入必须复现同样的推导链，不能出现同一输入两次不同结论。

针对以上三类，我整理了验证用例，重点核对「结论 + 推导链」而不只是最终结论——因为医学类专家系统里，**结论对但依据错**同样是缺陷。
